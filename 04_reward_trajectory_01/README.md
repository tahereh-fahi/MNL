# Reward Trajectory 01

This project is a thesis companion for modeling interval-coded reward trajectories with Hawkes processes. It asks whether reward events are clustered, self-exciting, or bursty over time, using event-level temporal point-process analysis.

## Contents

- [`CRAVE_HawkesProcess_Analysis.ipynb`](CRAVE_HawkesProcess_Analysis.ipynb): end-to-end Hawkes-process analysis notebook.
- [`CRAVE_PredictedAddictiveRewardPatterns.docx`](CRAVE_PredictedAddictiveRewardPatterns.docx): thesis write-up companion document.

## Notes

- The source data are interval-coded, so exact within-interval timing is approximated at the coding resolution used.
- This folder is curated for GitHub sharing and sits alongside the other MNL project materials.
