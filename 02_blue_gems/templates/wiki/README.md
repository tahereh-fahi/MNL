# Vampire Survivors gem references

Source: https://vampire.survivors.wiki/w/Experience_Gem

Downloaded from the wiki's original image files on 2026-08-01.

- `blue_standard.png`: standard blue Experience Gem sprite.
- `blue_dark.png`: dark-blue sprite labeled "Luminaire's gem" in the gallery.
- `blue_bright.png`: bright-blue sprite labeled "Luminaire's gem" in the gallery.
- `green_standard.png`: standard green Experience Gem sprite.
- `red_standard.png`: standard red Experience Gem sprite.

The two Luminaire sprites are used only as alternate blue appearance references
for this experiment. An XP-bar increase and valid pickup trajectory are still
required; template similarity by itself never creates a collected-gem event.
